=====================================================
  DELIRIO - CARPETA PARA TUS FOTOGRAFÍAS DE PRODUCTOS
=====================================================

¡Aquí puedes colocar todas las fotos de tus postres y bebidas!

1. CÓMO COLOCAR TUS FOTOS:
   Copia y pega tus fotos directamente dentro de esta carpeta:
   c:\Users\hp\Desktop\Delirio\assets\images\products\

2. NOMBRES SUGERIDOS PARA REEMPLAZAR AUTOMÁTICAMENTE:
   - cheesecake-frutos-rojos.jpg  -> Cheesecake de Frutos Rojos
   - tarta-chocolate-belga.jpg    -> Tarta de Chocolate Belga 70%
   - pie-limon.jpg                -> Pie de Limón Merengado
   - tiramisu-vasito.jpg          -> Tiramisú de Especialidad en Vaso
   - tres-leches-vasito.jpg       -> Tres Leches Tradicional
   - mousse-maracuya.jpg          -> Mousse de Maracuyá
   - cookie-nutella.jpg           -> Cookie XL Nutella & Sal Marina
   - brownie-nuez.jpg             -> Brownie Húmedo de Chocolate & Nueces
   - alfajores-maicena.jpg        -> Alfajores Artesanales de Maicena
   - cheesecake-keto.jpg          -> Cheesecake Keto Sin Azúcar
   - brownie-fit-avena.jpg        -> Brownie Fit de Avena y Cacao
   - cafe-filtrado.jpg            -> Café Filtrado de Especialidad
   - latte-arte.jpg               -> Latte de Especialidad
   - te-helado-artesanal.jpg      -> Té Helado de Frutos Rojos

3. SI TUS FOTOS TIENEN OTROS NOMBRES O FORMATOS (.png, .webp):
   Solo abre el archivo:
   c:\Users\hp\Desktop\Delirio\js\products.js
   y cambia el nombre del archivo en la línea correspondiente al postre.

4. FOTOS DE RESPALDO (FALLBACK):
   Si dejas algún postre sin foto o aún no la tienes lista, la página web
   mostrará automáticamente una fotografía profesional para que tu tienda
   nunca se vea vacía ni rota.
